# 🎂 Age Calculator

**Uncover the secrets of your age with our interactive age calculator!*
</div>

---

## 📖 About

A clean, lightweight web application built with pure **HTML**, **CSS**, and **JavaScript** that calculates your exact age in **years, months, and days** from your date of birth — no frameworks, no dependencies.

---

## ✨ Features

- 📅 Native date-picker for easy date-of-birth selection
- ⚡ Instant age result on button click — years, months **and** days
- 🎨 Vibrant, centered card UI with custom CSS
- 💻 Zero dependencies — runs directly in any browser

## 🚀 Getting Started

### Prerequisites

All you need is a modern web browser (Chrome, Firefox, Edge, Safari).

### Run Locally

1. **Clone the repository**
   ```bash
   git clone https://github.com/Sai-manoj-ranga/age-calculator.git
   ```

2. **Navigate into the folder**
   ```bash
   cd age-calculator
   ```

3. **Open the app** — just double-click `age.html` or run:
   ```bash
   open age.html       # macOS
   start age.html      # Windows
   xdg-open age.html   # Linux
   ```

---

## 🧑‍💻 Usage

1. Open `age.html` in your browser.
2. Click the **date input** and select your date of birth.
3. Click **"Calculate Age"**.
4. Your age is displayed instantly: *"You are X years, Y months, and Z days old."*
